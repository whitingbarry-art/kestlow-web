Search and sort leads (KES-115). A search box on Leads finds leads by town, street, postcode or council (Chislehurst, BR7, BR7 6LT), asking the API once typing pauses, and keeps the search in the address bar so it can be bookmarked or shared. A Sort menu offers newest first, nearest first or decision due soonest, remembered on this device. The number of matching leads is announced to screen readers, a search with no matches says so with a Clear search button, and Escape clears the box.
