Make push alerts work on iPhones and on every device (KES-118). A web app manifest, with Kestlow's name, colours and icons (a maskable one for Android), lets Kestlow go on a Home Screen and open full-screen like an app, which iPhones and iPads need before they allow push. On an iPhone or iPad in Safari, the Push switch now explains, step by step, how to add Kestlow to the Home Screen, and asks for iOS 16.4 or later where the Home Screen app still has no push. When push is on for the account but this device doesn't get the alerts, Alerts offers "Turn on for this device". The push description now says what really happens: "Each evening, as new leads come in".
