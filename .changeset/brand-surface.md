Give the navy areas some depth: the desktop sidebar, the mobile top bars, and the sign-in and waitlist headers now share a "brand surface", a faint blueprint grid over a gentle navy gradient with a soft amber glow in the top corner. The sidebar marks the current page with an amber bar. The lead map gets the same faint grid, drawn as its own Leaflet layer between the map tiles and the pin, so the pin and the OpenStreetMap attribution stay on top. It's decoration only: the contrast tests check every text colour against the surface's lightest point in both themes, and Windows high-contrast mode drops it.
