Replace the emoji icons with Lucide SVG icons, which stay sharp at any zoom and look the same on every device: clipboard, bookmark and bell in the navigation, sun-and-moon for the theme switch, log-out for Sign out, and a check mark on the Saved button, the plan cards and the waitlist promises. The Alerts bell had shown as an empty box where no emoji font was installed. Icons are hidden from screen readers, as every one sits beside its label. The active bottom-nav icon uses the darker amber so it keeps 3:1 contrast, and "Switch light / dark" is now "Change theme" so it fits beside its icon.
